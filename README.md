# 🧠 Brain Tumor Detection using CNN & Streamlit

A Convolutional Neural Network (CNN) deep learning model built with TensorFlow/Keras to detect brain tumors from MRI scans, deployed with an interactive Streamlit web interface.

## 🚀 Features
- **Binary Classification:** Classifies MRI scans into *Tumor Detected* or *No Tumor Detected*.
- **Live Inference:** Instant prediction and confidence scores.
- **Web App:** Simple user interface built with Streamlit.

## 🛠️ Tech Stack
- **Python**
- **TensorFlow / Keras**
- **Streamlit**
- **OpenCV / PIL**
- **NumPy & Matplotlib**
